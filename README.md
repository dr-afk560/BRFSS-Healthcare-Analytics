# BRFSS Healthcare Access Dashboard

## Project Overview

This project analyzes healthcare access in the United States using 2023 Behavioral Risk Factor Surveillance System (BRFSS) data. SQL was used to clean and analyze the data, and Tableau was used to build an interactive dashboard that highlights healthcare affordability, insurance coverage, and preventive care across income groups.

## Objectives

- Analyze cost-related barriers to healthcare by income
- Compare health insurance coverage across income groups
- Examine preventive care utilization
- Present findings through an interactive Tableau dashboard

## Tools & Technologies

- PostgreSQL
- SQL
- Tableau
- Microsoft Excel

## Key Findings

- Lower-income populations were significantly more likely to delay medical care because of cost.
- Health insurance coverage increased as household income increased.
- Preventive care utilization generally improved with higher income levels.
